## Overview

Wind-turbine inspection with unmanned aerial vehicles (UAVs) is limited by three problems: field data
is scarce, detectors trained on clean imagery do not transfer to fog / low light / motion blur, and
defects span more than an order of magnitude in scale.

The accompanying paper addresses these problems with diffusion-based adverse-environment synthesis, a
Feature Calibration Module and a Multi-Scale Feature Aggregation module, evaluated on a leakage-free
re-split of WTVD. What this repository contributes meanwhile is the **benchmark definition** and
**reference points on it**, so that other groups can reproduce the comparison under the same protocol.

### Benchmark definition

Fog is generated by HazeGen (a ControlNet built on Stable Diffusion 2.1); the remaining three
families by explicit physical operators. Every degraded image inherits the bounding boxes and the
split of its clean source, so the benchmark carries full supervision at no extra annotation cost.

| family | method | controllable parameters (range) |
|---|---|---|
| Fog | HazeGen (generative) | mixture coefficient $w=0.85$, 50 sampler steps, haze text prompt |
| Motion blur | linear motion PSF | PSF length $L$ 5–14 px, angle $\theta$ 0–180°, noise $\sigma_n$ 0–2.5 |
| Low-light | illumination + sensor model | attenuation $\gamma$ 1.3–1.9, gain $g$ 0.60–0.85, read noise $\sigma_r$ 0.010–0.028, shot scale $s$ 0.45–0.70 |
| Composite | fog → low-light → blur | $\gamma$ 1.25–1.70, $g$ 0.65–0.90, $\sigma_r$ 0.008–0.020, $s$ 0.50–0.75, $L$ 4–10 px, $\sigma_n$ 0–2.0 |

Machine-readable form: [`configs/degradation_params.json`](configs/degradation_params.json).

## Datasets

The public WTVD export holds 4467 images but only **1895 distinct source photographs**, and its
published split placed augmented copies of the same photograph into different subsets. The split
released here regroups the images by source and confines every near-duplicate cluster to a single
split, so no test image derives from a training photograph.

| dataset | splits (train / val / test) | images | size |
|---|---|---|---|
| **WTVD** (clean, leakage-free) | 3577 / 444 / 177 | 4198 | ~167 MB |
| **Extreme-WTVD** (4 families pooled) | 14308 / 1776 / 708 | 16792 | ~3.9 GB |

Object size $\sqrt{wh}$ spans from below 16 px to above 96 px; on the clean test split the
distribution is 55.6 % > 96², 39.3 % in 32²–96², 4.8 % in 16²–32² and 0.3 % < 16² (392 boxes).

> The worst fog case — in-box SSIM 0.185, against a median of 0.618 — is disclosed in the paper as a
> failure case, so users know where annotation transfer is least reliable.

> **† On the single-seed rows.** The six standard detectors were each trained three times
> (seeds 0/1/2), and their ± values are sample standard deviations over those runs. DANN, Advent and
> YOLO-RAW are published here from one run each (seed 0), because the repeats were not retained. The
> clean-split values of those three cannot therefore be compared to the ± columns on an equal
> footing, and their Extreme-WTVD values are seed 0 only as well. Note also that DANN and Advent lose
> AP@50:95 on *every* split relative to their own source model — the clean arm they were adapted from
> scores 17.45 AP@50:95 on clean and gains only on the low-light family (+1.66 and +1.77 points) while
> giving up 5.78 and 6.00 on clean. This is the known cost of adversarial domain alignment on a
> detection objective (its box and DFL terms already dominate the loss), not an artefact of the single
> run.

DANN and Advent start from the converged clean-trained YOLO 11 and are adapted on the leakage-free
splits for 30 epochs each (λ<sub>dom</sub> = 0.5 with the Ganin ramp), so their rows are not directly
comparable to the from-scratch detectors. Every baseline loses most of its accuracy on the synthetic
pool — this is the domain gap the benchmark is designed to expose.

### 6 · Failure-mode decomposition (clean-trained baseline)

Each of the 392 annotated boxes falls into exactly one bin. Operating threshold 0.25, second pass at
0.001 to separate "low confidence" from "never represented".

| condition | TP | wrong class | class overlap | loc. 0.1–0.5 IoU | below threshold | invisible |
|---|---|---|---|---|---|---|
| clean | 49.2 % | 0.8 % | 1.0 % | 24.5 % | 14.3 % | 5.9 % |
| fog | 9.2 % | 0.8 % | 0.8 % | 6.1 % | 23.0 % | 57.4 % |
| motion blur | 31.6 % | 1.0 % | 1.0 % | 16.6 % | 20.9 % | 23.5 % |
| low light | 3.3 % | 0.8 % | 0.8 % | 2.3 % | 14.8 % | 77.8 % |
| composite | 9.9 % | 0.3 % | 0.3 % | 6.9 % | 31.6 % | 49.0 % |

Under clean conditions the dominant losses are **localization and confidence**, not invisibility;
complete invisibility only dominates under fog and low light. Per-condition calibration (ECE) is
0.057 clean, 0.118 fog, 0.045 motion blur, 0.132 low light and 0.151 composite. Full per-class and
per-size breakdowns: [`results/failure_taxonomy.txt`](results/failure_taxonomy.txt).

### Reading these numbers

* **The ordering among baselines is indicative, not a ranking.** The seed spread reaches between
  half and five-sixths of the total span between the best and worst detector, and all fifteen
  pairwise ±1 sd intervals overlap for AP@50:95 (mean within-model sd 0.66 against a six-model span
  of 1.13). See [`results/multiseed_report.txt`](results/multiseed_report.txt).
* **The domain gap is substantial.** A clean-trained YOLO 11 drops from 65.9 % box recall
  (IoU ≥ 0.5) on clean images to 38.5 % under motion blur, 22.5 % under the composite condition and
  18.7 % under low-light — while remaining non-trivial everywhere, so the task stays well posed.
* **Only 177 test images.** Absolute values shift by a point or two if the split is regenerated;
  report differences larger than the seed spread.

## Reproducing the baselines

The baseline rows need no code from this repository — they are stock Ultralytics detectors:

```bash
pip install ultralytics==8.4.160
```

```python
from ultralytics import YOLO

# seed 0 of the YOLO 11 baseline; repeat with seed=1, 2
m = YOLO("yolo11n.pt")
m.train(data="configs/wtvd.yaml", epochs=400, batch=16, imgsz=640,
        optimizer="SGD", lr0=0.01, momentum=0.937, weight_decay=0.0005,
        patience=100, amp=True, seed=0, project="runs", name="yolo11n_clean_seed0")
```

```bash
yolo detect val model=runs/yolo11n_clean_seed0/weights/best.pt \
                data=configs/extreme_wtvd.yaml
```

DANN and Advent are standard implementations (Ganin et al.; Vu et al.) applied on top of the
converged clean-trained YOLO 11 (30 epochs, lr 0.001, λ<sub>dom</sub> 0.5 with the Ganin ramp,
source = clean images, target = the four Extreme-WTVD families). YOLO-RAW follows the published
adverse-weather model.
