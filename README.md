## Overview

Wind-turbine inspection with unmanned aerial vehicles (UAVs) is limited by three problems: field data
is scarce, detectors trained on clean imagery do not transfer to fog / low light / motion blur, and
defects span more than an order of magnitude in scale.

This repository accompanies a paper that addresses these problems with three components —
diffusion-based adverse-environment synthesis, a Feature Calibration Module (FCM) and a Multi-Scale
Feature Aggregation (MSFA) module — and evaluates them on a leakage-free re-split of WTVD. The
mechanism of the proposed modules is described in the manuscript; here we publish the **benchmark
definition** and the **baseline reference points** against which the method is measured, so that
other groups can reproduce the comparison on the same data and protocol.

### Benchmark descriptors

Fog is generated by HazeGen (a ControlNet built on Stable Diffusion 2.1); the remaining three
families by explicit physical operators. Every degraded image inherits the bounding boxes and the
split of its clean source, so the benchmark carries full supervision at no extra annotation cost.

| family | method | controllable parameters (range) |
|---|---|---|
| Fog | HazeGen (generative) | mixture coefficient $w=0.85$, 50 sampler steps, haze text prompt |
| Motion blur | linear motion PSF | PSF length $L$ 5–14 px, angle $\theta$ 0–180°, noise $\sigma_n$ 0–2.5 |
| Low-light | illumination + sensor model | attenuation $\gamma$ 1.3–1.9, gain $g$ 0.60–0.85, read noise $\sigma_r$ 0.010–0.028, shot scale $s$ 0.45–0.70 |
| Composite | fog → low-light → blur | $\gamma$ 1.25–1.70, $g$ 0.65–0.90, $\sigma_r$ 0.008–0.020, $s$ 0.50–0.75, $L$ 4–10 px, $\sigma_n$ 0–2.0 |

Machine-readable form: [`configs/degradation_params.json`](configs/degradation_params.json).

## Datasets

The public WTVD export holds 4467 images but only **1895 distinct source photographs**, and its
published split placed augmented copies of the same photograph into different subsets — 81.0 % of
test images share a source photograph with training. The split released here regroups the images by
source and confines every near-duplicate cluster to a single split.

| dataset | splits (train / val / test) | images | size |
|---|---|---|---|
| **WTVD** (clean, leakage-free) | 3577 / 444 / 177 | 4198 | ~167 MB |
| **Extreme-WTVD** (4 families pooled) | 14308 / 1776 / 708 | 16792 | ~3.9 GB |

### Classes

Seven defect categories, strongly imbalanced (dirt and peeling dominate):

```
nc: 7
names: ['burning', 'crack', 'deformity', 'dirt', 'oil', 'peeling', 'rusty']
```

Object size $\sqrt{wh}$ spans from below 16 px (hairline cracks) to above 96 px (spalling,
large-area corrosion), so the task is inherently multi-scale.

### Reading these numbers

* **The ordering among baselines is indicative, not a ranking.** With three seeds the seed spread
  reaches between half and five-sixths of the total span between the best and worst detector, and
  all fifteen pairwise ±1 sd intervals overlap for AP@50:95. See
  [`results/multiseed_report.txt`](results/multiseed_report.txt).
* **The domain gap is substantial.** A clean-trained YOLO 11 drops from 65.9 % box recall
  (IoU ≥ 0.5) on clean images to 38.5 % under motion blur, 22.5 % under the composite condition and
  18.7 % under low-light — while remaining non-trivial under every condition, so the task is well
  posed.
* **Failure modes differ by condition.** Under fog most of the operating-point loss is a confidence
  shortfall rather than invisibility; see
  [`results/failure_taxonomy.txt`](results/failure_taxonomy.txt).

## Reproducing the baselines

The baseline rows are produced with stock Ultralytics detectors — no custom layers — so they can be
reproduced without any code from this repository:

```bash
pip install ultralytics==8.4.160
```

```python
from ultralytics import YOLO

# seed 0 of the YOLO 11 baseline; repeat with seed=1, 2
m = YOLO("yolo11n.pt")
m.train(data="configs/wtvd.yaml", epochs=400, batch=16, imgsz=640,
        optimizer="SGD", lr0=0.01, momentum=0.937, weight_decay=0.0005,
        patience=100, amp=True, seed=0, project="runs", name="yolo11n_clean_seed0")
```

```bash
# evaluate on the synthetic pool
yolo detect val model=runs/yolo11n_clean_seed0/weights/best.pt \
                data=configs/extreme_wtvd.yaml split=test
```

DANN and Advent are standard implementations (Ganin et al.; Vu et al.) applied on top of the
converged clean-trained YOLO 11. YOLO-RAW follows the published adverse-weather model.
